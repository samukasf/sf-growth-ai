# Project Boundaries

Este repositório contém exclusivamente o produto SF Growth AI e os módulos oficialmente pertencentes a ele.

Regras:
- Não hospedar sites de clientes neste repositório.
- A branch histórica `srbrasa-public-preview` deve ser tratada apenas como fonte temporária para migração.
- Sr Brasa deve ter repositório, projeto Vercel e domínio próprios.
- Novos sites, previews e produtos independentes devem usar repositórios e projetos Vercel próprios.
